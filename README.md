### 🛡️ Open-source security tools I've built

- **[Tripwire](https://github.com/smakarim/tripwire)** — Security posture scanner for AI coding agents. Inventories MCP servers, detects plaintext secrets, captures runtime exposure, and exports SARIF and Sigma.
- **[Airlock](https://github.com/smakarim/airlock)** — Audit npm packages a PR adds or bumps before they execute. Catches typosquat, dependency-confusion, and malicious install-hook packages that CVE scanners miss.
- **[Revenant](https://github.com/smakarim/revenant)** — Recover deleted and force-pushed GitHub commits and scan them for live secrets.
- **[MCP n8n Security Scanner](https://github.com/smakarim/mcp-n8n-security-scanner)** — MCP server that statically scans n8n workflows for SSRF, code injection, unauth webhooks, hardcoded secrets, and PII egress. Includes STRIDE threat model.
- **[bbdiscover](https://github.com/smakarim/bbdiscover)** — Self-hosted bug bounty / VDP program discovery with CT-log real-time watch and Google Sheets output.
